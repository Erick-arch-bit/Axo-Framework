Axo es un framework cross-platform con motor
en Rust y UI en Lua. Renderiza con wgpu,
layout con Flexbox, y recarga en caliente.

Comenzar GitHub

cargo install axo-cli

Destinado a aplicaciones de nicho — dashboards embebidos, terminales POS, apps internas

Linux macOS Windows Android iOS Web

Todo lo que necesitas, nada que sobre

Rust Core

Motor escrito en Rust. Renderizado con wgpu (Vulkan/Metal/DX12/WebGL2). Layout con Taffy Flexbox.

Lua UI

Interfaz declarativa en Lua 5.4. Sin JS, sin npm. Tu UI es un árbol de tablas.

Hot Reload

Edita tu código Lua y ve los cambios al instante. Sin compilar, sin reiniciar.

Permisos

Sistema de permisos granular con default Denied. Geolocalización, sensores, cámara y más.

Componentes

View, Text, Button, Image, TextInput, ScrollView, FlatList, Spacer, Divider, Pressable, SafeAreaView.

CLI Tooling

axo-cli init, dev, build, release. Scaffolding, hot reload, y bundling.

Así se ve Axo

app/app.lua 
local UI = require("axo")

function onClick()
    log("Hello from Axo!")
end

function App()
    return UI.View({
        style = {
            width = "100%",
            height = "100%",
            backgroundColor = "#1a1a2e",
            flexDirection = "column",
            justifyContent = "center",
            alignItems = "center",
        },
        children = {
            UI.Text({
                text = "Hola desde Axo!",
                style = { fontSize = 28, color = "#ffffff" },
            }),
            UI.Button({
                text = "Clic aquí",
                onClick = "onClick",
                style = {
                    backgroundColor = "#e94560",
                    width = "200",
                    height = "50",
                    margin = "10",
                },
            }),
        },
    })
end

return App

Estado reactivo con useState

app/app.lua 
local UI = require("axo")

-- Estado que persiste entre re-renders
local count = UI.useState("counter", 0)

function handleIncrement()
    count.set(count.get() + 1)
end

function handleDecrement()
    count.set(count.get() - 1)
end

function App()
    return UI.View({
        style = {
            width = "100%", height = "100%",
            backgroundColor = "#1a1a2e",
            flexDirection = "column",
            justifyContent = "center",
            alignItems = "center",
        },
        children = {
            UI.Text({
                text = "Contador: " .. count.get(),
                style = { fontSize = 32, color = "#ffffff" },
            }),
            UI.Button({
                text = "+",
                onClick = "handleIncrement",
                style = { backgroundColor = "#e94560", width = "100", height = "50", margin = "5" },
            }),
            UI.Button({
                text = "-",
                onClick = "handleDecrement",
                style = { backgroundColor = "#0f3460", width = "100", height = "50", margin = "5" },
            }),
        },
    })
end

return App
