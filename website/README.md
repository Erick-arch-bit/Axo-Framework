# Axo Framework — Website

Página web oficial del framework Axo.

Live: [https://axo-framework.dev](https://axo-framework.dev)

## Desarrollo local

```bash
# Con cualquier servidor estático
python3 -m http.server -d website 8080
# o
npx serve website
```

## Stack

- HTML + CSS vanilla (sin frameworks JS)
- Fuentes: Inter (texto), JetBrains Mono (código)
- Sin dependencias, sin build step
